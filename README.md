# 🚀 Express + PostgreSQL + TypeScript CRUD API

A robust and type-safe backend application built with **Node.js**, **Express**, and **TypeScript**, utilizing **PostgreSQL** (via Neon DB) for data persistence. This project demonstrates full CRUD (Create, Read, Update, Delete) operations with a relational database.

---

## ✨ Features

- **Full CRUD Support**: Create, Read, Update, and Delete products seamlessly.
- **TypeScript Integration**: Strong typing for better developer experience and fewer runtime errors.
- **Neon DB Connectivity**: Leveraging cloud-native PostgreSQL for reliable data storage.
- **Error Handling**: Comprehensive try-catch blocks to manage database and server-side errors.
- **Relational Data Management**: Efficient data handling using the `pg` (node-postgres) library.
